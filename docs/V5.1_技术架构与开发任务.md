## 1. 老接口影响面分析

### 1.1 行为增强（接口签名不变，后端加 IM 副作用 —— 对线上老版本完全透明）

| 接口 | 增强内容 | 失败策略 |
|---|---|---|
| `POST /v3/family/groups` 创建家庭 | 创建成功后异步建 IM 群，写 `family_group.imGroupId` | IM 建群失败**不回滚家庭**，`imGroupId=null` 由对账 cron 补建 |
| `POST /v3/family/invites/redeem` 兑换入家庭 | 服务端 API 把 userId 静默拉入 IM 群 | 同上，cron 补拉 |
| `POST /v3/family/groups/:id/leave` 退出 | 同步退 IM 群 | best-effort + cron |
| `DELETE /v3/family/groups/:id` 解散 | 同步解散 IM 群 | best-effort + cron |
| `DELETE /v3/family/groups/:id/members/:userId` 踢人 | 同步踢出 IM 群 | best-effort + cron |
| `GET /v3/family/groups/me` / `me/all` | 响应**新增字段** `imGroupId`（老客户端忽略未知字段，无影响） | — |
| 首页各 query* 接口（高风险结果） | 命中高风险且成员 `shareQueryResults=true` → 落 family_event + 发播报卡 + 强提醒（接口响应不变） | 事件失败仅打日志，不影响查询返回 |

### 1.2 冻结（不删不改，新版客户端停用）

| 接口 | 说明 |
|---|---|
| `POST /v3/family/broadcast` 手动分享广播 | 语义被"求助卡 / 案例卡"取代。**其内部的 AI 检测、当日同内容去重、配额逻辑抽出复用**给自动播报 |
| `GET /v3/family/broadcasts` 官方消息列表 | 老版本继续拉取；新版家庭 Tab 是 IM 群聊，不再调用。历史官方消息不迁移进群 |

### 1.3 保留并复用（零改动或小改）

| 接口 | V5.1 用法 |
|---|---|
| `PUT members/me/preferences`（shareQueryResults） | 零改动。自动播报读此开关 —— 线上"自动广播 TODO"正式接通 |
| `PUT groups/:groupId/members/me/display-name` | 保留（自己改自己的称呼）。**新增群主版**见 §3 |
| `PUT members/:memberId/alias` 私人备注 | 零改动。显示优先级：alias > displayName > nickname（微信同款） |
| `GET members/status` / `v3UserHeartbeat` 关怀心跳 | 零改动。可选增强：IM 登录事件作为补充活跃信号 |
| `PUT members/:userId/elder-mode`、care-mutes 两个接口 | 零改动，通知偏好页整体链入群设置 |
| `POST /groups/:id/invites`（已加 shareLink） | 零改动（本期前置版本已完成） |
| `POST /api/user/v3/devices` 推送注册 | 零改动。IM 聊天推送走服务商通道（挂同一 APNs 证书），风险强提醒走自有通道 |

### 1.4 常量调整

| 项 | 现值 | 新值 | 兼容性 |
|---|---|---|---|
| `FREE_MAX_FAMILY_MEMBERS` | 3 | **5** | 只放宽，服务端判断，**老版本立即受益无需发版**；满员文案是服务端下发的，无写死风险 |

### 2.2 数据模型（Prisma 增量）

```prisma
// family_group 增量
imGroupId    String?  @map("im_group_id")      // IM 群 ID，null=待补建
imSyncedAt   DateTime? @map("im_synced_at")    // 最近对账成功时间

// family_member：无新增字段（群昵称复用 displayName，权限放宽见 §3）

model FamilyEvent {
  id          String    @id @default(cuid())
  groupId     String    @map("group_id")
  actorUserId String    @map("actor_user_id")
  cardType    String    @map("card_type")   // help_request/risk_alert/case_share/daily_scam/milestone
  riskLevel   String?   @map("risk_level")
  refType     String?   @map("ref_type")    // query/case/intel/conversation
  refId       String?   @map("ref_id")
  imMsgId     String?   @map("im_msg_id")
  status      String    @default("open")    // open/checking/dismissed/confirmed_safe/acknowledged
  handledBy   String?   @map("handled_by")
  handledAt   DateTime? @map("handled_at")
  readBy      Json?     @map("read_by")
  payload     Json?
  createdAt   DateTime  @default(now()) @map("created_at")
  @@index([groupId, createdAt])
  @@index([groupId, cardType, createdAt])
  @@map("family_events")
}

model ImModeration {                          // 举报 + 拉黑
  id         String   @id @default(cuid())
  type       String                            // report / block
  reporterId String   @map("reporter_id")
  targetId   String?  @map("target_id")        // 被拉黑人
  imMsgId    String?  @map("im_msg_id")
  reason     String?
  status     String   @default("pending")
  createdAt  DateTime @default(now()) @map("created_at")
  @@map("im_moderations")
}
```

### 2.3 关键链路时序（文字版）

**自动播报**：`queryUrl 高风险` → family-event.service.emit(`risk_alert`) → ① 写 family_event ② 服务端向 IM 群发自定义消息（不触发 IM 推送，静默）③ 自有 APNs 强提醒发给群内其他成员（respect care-mutes / 通知偏好）。复用原 createBroadcast 的**当日同内容去重 + 配额**逻辑。

**求助**：客户端 `POST /family/help-request { queryId | conversationId }` → 服务端取 AI 结论快照 → emit(`help_request`) → 卡片进群 + 强提醒子女。同一 conversationId 二次提交 → 更新原 family_event 与原 IM 消息（修改消息），不新发。

**chips 处置**：客户端点 chip → ① IM SDK 直接发预设文本消息（走 IM 通道）② `POST /family/events/:id/handle { action }` 落处置。两步任一失败独立重试，处置接口幂等（同人同事件重复 handle 覆盖）。

**已读**：IM SDK 群消息已读回执 → 客户端聚合后 `POST /family/events/:id/read`（仅卡片消息上报，普通聊天不上报）。

**对账 cron（每日）**：遍历 `imGroupId != null` 的家庭 → 比对成员表 vs IM 群成员 → 补拉/补踢/补建；`imGroupId == null` 的补建群。所有 IM 写操作幂等。

### 2.5 IM 服务商接入配置（一次性）

1. 腾讯云国际站账号 → 创建 Chat 应用（拿 SDKAppID + 密钥）；
2. 控制台关闭客户端建群/加群权限（全部走服务端 REST）；
3. 上传 APNs 推送证书（挂现有 .p8）；
4. 服务端配 `TIM_SDKAPPID` / `TIM_SECRET` 环境变量（Railway）；
5. 群类型选 Work（私有群、不可搜索、仅服务端邀请）。

## 5. 风险清单（技术）

| 风险 | 对冲 |
|---|---|
| IM 服务不可用 → 家庭 Tab 白屏 | 灰度开关一键回退旧页；家庭管理功能（成员/邀请/设置）不依赖 IM 长连接 |
| 新老版本混跑：老版本用户看不到群聊内容 | 播报类事件双写：IM 卡片 + 旧 broadcasts 表（Sprint 2 双写一个版本周期，老接口冻结但数据不断供） |
| 群成员漂移（IM 副作用失败） | 幂等 + 每日对账 + 告警；家庭 DB 永远是事实源 |
| UserSig 泄露 | 有效期 7 天、绑定 userId、服务端可吊销（改密钥） |
| 卡片 payload 版本演进 | payload 带 `v` 字段，客户端未知版本降级渲染为纯文本 + deepLink |
