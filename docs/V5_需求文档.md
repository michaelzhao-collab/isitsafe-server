# IsItSafe / StarLens AI — V5 需求文档（市场战略期）

> **版本**: V5 Planning Draft v1
> **日期**: 2026-06-21
> **状态**: 待评审
> **背景**: V1–V4 已把"反诈一体化"基础设施铺完（AI 多模态分析 / 情报+案例库 / 家庭组 / 长辈模式 / 深伪检测 / 5 SKU 订阅）。V5 不再加新模块，而是**基于市场竞品分析**，集中砸 1–2 件能形成护城河的事。
> **前置**: 本文档不替代 V3/V4，是在 V4 收尾即将送审 1.1.0 的时点上，对**下一阶段产品方向**做战略性收敛。

---

## ⚠️ 0. 关键判断（必读）

V1–V4 阶段我们一直在"做加法"：模块越来越多、功能越来越广。V5 必须做减法——**不再加新 Tab，不再加新模块**，集中把已有差异化打透。

### 0.1 一句话判断

> StarLens AI 目前是"AI 通用反诈助手"，特别像 Norton Genie 的中文 + 家庭版。要赢，必须**选一边走**——
> - **要么** 把"家庭 + 老人守护"做成大件（国内外都没人做透，**推荐**）；
> - **要么** 把"AI 多模态 + 深伪"做成专家级（窗口期还有 ~1.5 年）。
>
> 不要再加新模块了，集中砸 1–2 件。

### 0.2 V5 不做的事

| 不做 | 原因 |
|---|---|
| 加新一级 Tab | 已经 4 个 Tab，再加用户认知爆掉 |
| 再做新查询品类（如行程、商品、合同） | 偏离反诈定位，稀释品牌 |
| 加新订阅 SKU | 5 个 SKU 已经够多，先把现有的转化率打透 |
| 做电话拨号器 / 完整短信 App | iOS 沙箱不允许，做了也是残废 |

## 1. 市场竞品分析

### 1.1 主要对手矩阵

| 市场 | 主要对手 | 核心护城河 | 对我们的威胁等级 |
|---|---|---|---|
| 🇨🇳 国内 | **国家反诈中心 App**（公安部官方，0 元，强制装机推广） | 数据权威性 + 装机量 + 系统级权限 | 🔴 极高 |
| 🇨🇳 国内 | 腾讯手机管家、360 安全卫士 | 工具箱式综合 + 装机量 | 🟡 中（反诈非核心） |
| 🇨🇳 国内 | 微信安全中心、银行 App 内嵌反诈模块 | 嵌入既有用户动线 | 🟡 中（场景化但单一） |
| 🌍 海外 | **Truecaller**（月活 4 亿+，做了 16 年） | 来电号码库 + 全球用户上报网络 | 🔴 极高 |
| 🌍 海外 | Hiya、Robokiller | 来电过滤 + 运营商合作 | 🟡 中 |
| 🌍 海外 | **Norton Genie**（24 年起 AI 反诈助手） | Norton 品牌信任 + 全球分发 | 🔴 极高（最直接对手） |
| 🌍 海外 | Bitdefender Scamio、Aura | 老牌安全公司 + 保险增值 | 🟡 中 |

### 1.2 SWOT 分析

#### 🟢 优势（Strengths）

| # | 优势 | 为什么是真优势 |
|---|---|---|
| S1 | **多模态分析一站全包**（截图/语音/链接/电话/公司/二维码/深伪） | 国家反诈中心 + Truecaller 都做不到这种"啥都能丢进来问"的形态。**唯一真正的差异化标签** |
| S2 | **家庭账户 + 长辈模式** | 子女买单帮父母守护，国内**几乎无对手**，海外只有 Aura 做得比较深。LTV/ARPU 上限的来源 |
| S3 | **AI 大模型解释力** | 案例库+情报+个案分析能讲"为什么是骗"，比 Truecaller 黑名单弹窗更有教育属性 |

#### 🟡 弱点（Weaknesses）

| # | 弱点 | 影响 |
|---|---|---|
| W1 | **没有来电拦截 / 短信过滤** | 反诈领域**最强**用户需求，Truecaller 的根 |
| W2 | **数据库权威性"虚"** | 国家反诈中心是公安直供，我们更多是 AI 整理 + UGC 举报。reviewer 和用户都会问"你凭啥比官方准" |
| W3 | **家庭功能偏被动"心跳"** | 比起 Life360 / Aura 还差地理位置 / 紧急求助 / 异常行为告警 |
| W4 | **首页 4 模态全走"问 AI"** | AI 耐用但慢（timeout 300s 就是怕断），用户体验是"等"而不是"一秒就拦" |

#### 🔴 威胁（Threats）

| # | 威胁 | 应对原则 |
|---|---|---|
| T1 | **苹果系统内置追平能力**（iOS 24/25 起 Live Voicemail / Live Translation / Safari Scam Detection 都系统侧了） | **不做苹果在做的事**，护城河必须在系统层之外 |
| T2 | **Norton / Bitdefender 大厂入场 AI 反诈助手** | 品牌信任溢价拼不过，必须靠**垂直人群（老人）+ 强场景（家庭群）** 错位竞争 |
| T3 | **国内"国家反诈中心"降维打击** | 不在"权威库"维度硬碰，走"国家反诈中心做不到的领域"（家庭联动、AI 解释、内容化） |

## 2. 战略主线

### 2.1 推荐方向：**家庭 + 老人守护**（主推）

**理由**：
- 国内外都没人做透，**蓝海**。
- 真实付费方（子女）和真实用户（老人）分离，**对应你已有家庭账户结构**。
- LTV 高（家庭包 ARPPU > 单人 3 倍）。
- 续费率高（保护父母不是一锤子买卖，是终身订阅）。

### 2.2 辅助方向：**AI 多模态 + 深伪**（差异化护城河）

**理由**：
- AI 拟声/换脸诈骗 2024-26 爆发期，**只有 AI 公司能做**。
- 窗口期约 1.5 年（之后大厂都会跟进）。
- 已有 `DeepfakeStreamClient` 骨架，技术门槛低。

## 3. 已有功能深挖（P0–P1）

按 ROI 排序的三大深挖方向。

### 3.1 【P0】家庭关怀升级：从"心跳监测"到"风险事件群播报"

#### 现状
- 家庭组、关怀提醒、活跃状态已就位（V4 已完成）。
- 但只是"心跳监控"——子女知道父母**在用手机**，不知道**遇到了什么**。

#### V5 要做的

**3.1.1 风险事件家庭群播报（核心）**

- 老人在 App 内查询/识别到**高风险**内容时，**自动一键推给家庭群**。
- 推送内容："📢 您父亲 1 分钟前查询了一条链接，AI 判定 **95% 是诈骗（投资类）**。建议给他打个电话。"
- 子女收到后可一键：① 拨打老人电话 ② 在家庭群发消息提醒 ③ 标记"已处理"。
- **为什么重要**：老人就算被告知危险也会半信半疑，**只有子女打电话过去说"别按"才真的拦得住**。

**3.1.2 子女代查询（核心）**

- 老人把可疑短信/链接/电话**截图发到家庭群**（微信/iMessage 等任意 IM）。
- 子女在自己 StarLens App 里**替父母查询**，AI 分析后**直接回复到家庭群**。
- **价值**：老人不用学会用 App。父母端只需要打开关怀提醒。

**3.1.3 家庭风险周报**

- 每周日给家庭组的"管理员"（通常是子女）推送：
  - 本周父亲遇到了 5 次可疑链接、3 次陌生来电
  - AI 拦下 2 次高风险
  - 与上周相比 ⬆️ 风险事件增加 30%（最近骗子瞄上了你家）
- **为什么重要**：子女是付费方，需要"看到我的钱花在哪了"——直接影响**续费率**。

#### 实现复杂度
- 后端：需要"家庭风险事件流" + 周报聚合任务（已有家庭组基建，~中等）
- iOS：家庭组消息中心 UI + 代查询入口（~中等）
- 推送：APNs 推送已就位（V4 V4-P3 完成）
- **预估**：2 周

---

### 3.2 【P0】深伪 / AI 拟声识别：从"埋藏功能"提级为"首页主入口"

#### 现状
- `DeepfakeStreamClient` 已有，技术骨架在了。
- 但当前是分享扩展（Share Extension）入口或埋藏深处，用户**不知道**这个能力存在。

#### V5 要做的

**3.2.1 深伪检测上首页**

- 首页主入口加"语音/视频深伪检测"按钮。
- 支持：① 麦克风实时录音检测 ② 上传已有录音/视频文件 ③ 视频通话录屏检测。
- 输出："此音频 92% 概率为 AI 合成，特征：基频抖动异常 / 元音衔接不自然"。

**3.2.2 亲情声纹（差异化王牌）**

- 用户在家庭组里注册时，**录 5 秒家人的真实声音**。
- 未来收到陌生来电时，可以**上传一段录音让 App 比对**：这是不是你妈/你爸的真声？
- **为什么独有**：竞品没有。**对老人极度有用**——AI 拟声电话来时，最大的防线就是"这听起来像不像我女儿"。

**3.2.3 视频换脸检测**

- 微信视频通话录屏上传分析。
- 输出眨眼频率、面部光照一致性、嘴型同步度等指标。
- 标注"建议视频时让对方做出某动作（摆手、转头）来识破换脸"。

#### 实现复杂度
- 后端：声纹注册存储 + 比对接口（~中等，需要选声纹模型）
- iOS：首页改版 + 录音/录屏入口（~中等）
- 模型：深伪检测目前 80% 准确率，明确标注"辅助判断"
- **预估**：3 周

---

### 3.3 【P1】案例库 + 情报合并为"每日一骗"内容产品（**自传播引擎**）

#### 现状
- 已有大量案例 + 情报数据。
- 目前是"被动查询"——用户搜了才看到。

#### V5 要做的

**3.3.1 每日精选**

- 每天 1 条"今天这个骗局长这样"——AI 自动从最新情报里选 1 条高传播性的。
- 卡片化设计：图 + 标题 + 3 句话 + "看完整分析"按钮。
- 推送时间：18:00 晚饭后（最高打开率时段）。

**3.3.2 一键分享给家庭群 / 朋友圈**

- 卡片内置分享按钮，可分享到微信 / iMessage / 朋友圈 / 抖音。
- **分享卡片底部带"StarLens AI 出品"水印 + 二维码** → **零成本拉新引擎**。
- 这是国内做 toC 反诈 App **唯一能跑通的低成本获客**。

**3.3.3 案例库地区分发**

- 北京老人看到的诈骗案例 ≠ 广州的（电信诈骗高发类型有地域性）。
- 后端按用户注册城市/IP 分发。

#### 实现复杂度
- 后端：每日精选选品策略（人工+AI 半自动）+ 分享卡片图生成（~中等）
- iOS：分享面板增强（~小）
- **预估**：2 周

## 4. 市场强需求但未做（P0–P2）

### 4.1 【P0】CallDirectoryExtension 来电识别（**反诈 App 最缺的那块**）

#### 痛点
- 用户输入电话号码到首页搜（`queryPhone`）才能查。
- 但**真正诈骗电话来的时候**用户根本来不及打开 App。
- 这就是为什么 Truecaller 立身之本是来电识别——这是反诈 App 用户**唯一愿意天天感知到你存在**的 surface。

#### V5 要做的

**4.1.1 系统拨号器来电标注**

- iOS `CallDirectoryExtension`——预加载号码库到系统拨号器。
- 陌生来电时**系统弹窗显示"疑似诈骗 - StarLens AI"**。
- 不需要打开 App。

**4.1.2 号码黑名单库怎么搞**

| 来源 | 国内 | 海外 |
|---|---|---|
| 第三方数据合作 | 360 / 腾讯安全 / 运营商数据（需采购） | Truecaller / Hiya 数据闭源 |
| 自建 | UGC 举报 + AI 文本分类 + 情报库已有标注 | 同左 |
| 实时查询 | 服务器 hash 查询（无需预加载） | 同左 |

**4.1.3 轻量版（推荐先做）**

- 不预加载完整黑名单，只**实时 hash 查询服务器**。
- 命中后系统标注"疑似风险 - 点开查看"。
- 优势：① 不依赖大库 ② 服务器实时更新 ③ 隐私友好

#### 实现复杂度
- iOS：新建 Extension Target + 数据同步逻辑（~中等）
- 后端：号码查询 API + 风险评分（已有 `queryPhone` 复用）
- 数据：先用 UGC + AI 标注起步，~中等
- **预估**：3 周

#### 为什么排 P0
> 没有它你就是个"偶尔被翻牌"的工具。

### 4.2 【P2】短信识别 / iMessage 过滤（海外做，国内不做）

#### 现状
- 完全未做。

#### V5 要做的

**iOS `ILMessageFilterExtension`**——陌生号码短信自动归到 Junk 分类。

#### 取舍

| 市场 | 做不做 | 原因 |
|---|---|---|
| 🇨🇳 国内 | ❌ | 国内运营商体系下 Junk 分类对用户感知极弱，投入产出比低 |
| 🌍 海外（美国 iMessage） | ✅ | 用户已习惯 iMessage 垃圾分类，转化感知强 |

#### 实现复杂度
- iOS：Extension + Filter 逻辑（~小）
- 后端：复用现有 query 接口
- **预估**：1 周（海外限定）

### 4.3 【P1】被骗后的"应急处置"链路（**几乎无人做的高价值赛道**）

#### 痛点
- 用户真的被骗了，第一反应不是再打开你 App——而是慌、不知道该报警找谁、银行卡怎么冻结。
- 市面上**几乎没有 App 系统化解决这个场景**。
- 但这恰恰是用户**愿意为之付费 / 推荐给亲友**的最强动机。

#### V5 要做的

**4.3.1 "被骗了怎么办" SOP 引导**

- 首页 / 案例详情页加"我被骗了"应急按钮。
- 点击后进入引导流程：

```
Step 1 → 一键拨打 110 / 国家反诈中心 96110
Step 2 → 一键调用银行卡紧急冻结
         （招行/工行/建行等有 URL Scheme，海外用 Plaid 等聚合）
Step 3 → 自动生成报案材料 PDF
         （聊天截图 + AI 分析报告 + 转账记录组装）
Step 4 → 报案后的跟进提醒（24h/72h/1w）
```

**4.3.2 反诈保险（增量收入实验）**

- 国内：众安、平安、阳光等多家保险公司有"反诈险"产品（年费 ~50 元，最高赔付 ~5 万）。
- 海外：Aura 已经在做（含 100 万美金 ID Theft Insurance）。
- **可作为家庭包内嵌权益**，或单独购买。
- **商业潜力**：保险佣金（10-25% 转介费）+ 律师服务转介 = **比订阅更高的单客价值**。

#### 实现复杂度
- iOS：SOP 引导流程 UI（~中等）
- 后端：报案材料 PDF 生成 + 跟进提醒任务（~中等）
- 商务：保险公司谈判（~大，3-6 个月）
- **预估**：MVP 2 周，保险接入另算

## 5. 商业化优化（P0）

### 5.1 当前 SKU 体系问题

5 个 SKU：周 / 月 / 年 / 家庭月 / 家庭年。

| 问题 | 现状 | V5 调整 |
|---|---|---|
| **没有 freemium 漏斗** | 代码里有 `freeQueryCountToday` 但未充分利用 | 明确"每日 N 次免费查询，会员无限"——用焦虑感转化 |
| **周订阅国内意义不大** | 国内付费习惯月/年，周订阅退订率高 | 国内隐藏周订阅，海外保留作打榜用 |
| **家庭包没被推到主位** | 单人订阅排第一 | **家庭包提到订阅页首屏第一位**，单人订阅第二位 |
| **缺少试用机制** | 直接付费门槛高 | 月订阅前 3 天免费试用（已有 `INTRO-MONTHLY-FIRST` 配置） |

### 5.2 转化漏斗设计

```
日活用户
  ↓ (查询次数耗尽时)
免费配额耗尽弹窗 → "再查 1 次只需 ¥6/月"
  ↓ (5-8% 点击)
订阅页（首屏家庭包 + 套路放大焦虑）→ "守护全家只需 ¥9/月"
  ↓ (1.5-3% 转化)
月订阅 / 家庭月订阅
  ↓ (家庭包 1 月体验后)
续费引导（"父母这月遇到 X 次风险，StarLens 拦下 Y 次"）
  ↓ (60-75% 续费率)
年订阅升级
```

### 5.3 反诈保险作为增值权益

- 家庭年订阅默认含"反诈保险 100 万人民币保额"（与保险公司谈批量价格）。
- 单点：保险费在保险公司侧 ~30-50 元/年，但用户感知价值 = 100 万保障。
- **对家庭包 ARPPU 提升预期**：30-50%。

### 6.2 不做（明确划线）

| 不做的事 | 原因 |
|---|---|
| 加第 5 个 Tab | 认知爆炸 |
| 商品/合同/行程查询 | 偏离反诈定位 |
| 完整拨号器 / 完整短信 App | iOS 沙箱不允许 |
