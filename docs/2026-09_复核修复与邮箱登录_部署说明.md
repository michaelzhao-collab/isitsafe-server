## 二、部署要求

### 服务端（Railway）

1. **新增环境变量**（`.env.example` 已同步）：
   - `BREVO_API_KEY` —— 已配置
   - `MAIL_FROM_EMAIL=no-reply@starlensai.com`、`MAIL_FROM_NAME=StarLens AI`（不配则用此默认值）
   - `ALLOW_APPLE_RELAY_EMAIL=false`（发信域名在苹果开发者后台登记后再改 true）
2. **迁移**：本轮零新增。`start:prod` 会自动跑 `prisma migrate deploy`，把此前未 apply 的 3 个 V5.1 迁移应用上去（20260708 / 20260710 / 20260713）。
3. **Redis 必须可用**：登出吊销 token 与邮箱验证码都依赖 Redis。前者 Redis 故障时降级放行，后者**故障时拒绝**（验证码是身份凭证，不能放行）。

### iOS

代码在仓库里，但**线上 App Store 仍是 1.1.0**，本地工程是 1.2.0(6)。这批 iOS 改动要随 1.2.0 一起发版，发版前需真机回归（见第五节）。

### admin

Cloudflare Pages 若跟随仓库自动构建则无需动作；否则手动触发。

## 三、上线后对老用户的行为变化（必读）

| # | 变化 | 影响 | 应急开关 |
|---|---|---|---|
| 1 | **无密码老账号登不上** | 早期短信时代注册、`password_hash` 为空的账号。App Store 首发 2026-04-06 晚于密码登录上线 2026-04-01，Apple 登录不写手机号，所以应只剩内测账号。上线前跑：`SELECT count(*) FROM users WHERE phone IS NOT NULL AND password_hash IS NULL;` | `ALLOW_LEGACY_PASSWORD_CLAIM=true` 恢复旧行为（用完立即关） |
| 2 | **配额部署当天一次性重置** | 每日配额 key 从服务器 UTC 日期改为用户所在时区日期，国内用户当天多几次额度，次日起正常 | 无需处理 |
| 3 | **多家庭用户推送量上升** | 高风险自动播报从「只发第一个家庭」改为「发到全部家庭」 | 无 |
| 4 | **邮箱登录从「禁用」变为「需验证码」** | 此前该分支被临时关闭；现在必须带一次性验证码 | 无 |
| 5 | **登出后旧 access token 立即失效** | 此前 7 天内仍可用 | Redis 故障自动降级 |
| 6 | **每日一骗后台入参严格校验** | 非法 `riskLevel` / `action` 返回 400，不再静默兜底 | 无 |
| 7 | **`getMyBroadcasts` 跨家庭聚合** | 老客户端可能看到更多条广播（上限 100 不变） | 传 `?groupId=` 可过滤 |
| 8 | **WebSocket 新增 4403 关闭码** | 被禁用/删除的账号会被踢下线；新版 iOS 已按不可重连处理 | 无 |

## 四、上线后验证清单

```bash
# 老接口存活（不需登录）
BASE_URL=https://api.starlensai.com Server/scripts/smoke-test-v3.sh

# 新端点存在（应返回 400 邮箱格式错误，而不是 404）
curl -s -X POST https://api.starlensai.com/api/auth/email/send-code \
  -H 'content-type: application/json' -d '{"email":"x"}'

# 邮箱免验证登录已关闭（应 400，而不是 201 带 token）
curl -s -X POST https://api.starlensai.com/api/auth/login \
  -H 'content-type: application/json' -d '{"email":"probe@example.com"}'

# 空内容查询已拦截（需 token；应 400）
```

## 六、仍未处理

- **单设备 refresh token**：第二台设备登录会踢掉第一台，父母/子女共用账号场景必现。需存多个会话，属产品决策。
- **官网协议与隐私政策只有英文**，无多语言机制。法务文案缺失，不宜机翻。
- **Google 登录**：App 在中国区在架且默认环境为 productionCN，Google 鉴权域名大陆不可达，暂缓。若做建议直接 Google Sign-In 而非 Firebase。
- **发信域名 MX**：根域名收不了信，用户回复验证码邮件会石沉大海。Cloudflare Email Routing 免费可补。
